# Social link artwork

- GitHub: official GitHub_Invertocat_White.svg from https://brand.github.com/GitHub_Logos.zip . The local icon wrapper adds a contrasting background without recolouring the mark.
- LinkedIn: official in-logo/LI-In-Bug.png from https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip . A compact PNG preserves its proportions.
- Gmail badge: standard Simple Icons Gmail geometry rendered by https://img.shields.io/badge/Gmail-EA4335?style=flat-square&logo=gmail&logoColor=white . This replaces the earlier hand-drawn envelope; it is a locally stored link badge, not a credential.

No social icon needs an external image request at runtime. The Gmail badge links to the existing `mailto:` address, which uses the reader's configured mail application.
