# Colour icons for the Tech Stack animation

This collection supplies the Tech Stack showcase and the shared `scripts/brand_icons.py` resolver for architecture diagrams, hero workflows, role graphics, and detailed tech tags. Product marks use the same colour treatment across the page.

Original-colour SVG variants are downloaded from the [Devicon repository](https://github.com/devicons/devicon), with file URLs and hashes recorded in `sources.json`. Five marks reuse the existing local product geometry with its brand colour. Naturally dark brand marks sit on a light contrast plate. The original product artwork is preserved without flattening multicolour icons to white.
